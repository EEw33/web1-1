# Web 1 Assignment Report

## 1. Objective

The goal of this project was to create a small multi-page static website using HTML and CSS. The site was designed to practice basic web development skills such as page structure, navigation, styling, tables, images, and layout design.

## 2. Description of the Work

I created a simple website with the following pages:

- Main page (`index.html`) — landing page with navigation links
- Part 1 (`part1.html`) — personal information section with hobbies, favorite websites, and a button interaction
- Part 2 (`part2.html`) — class schedule table and mood section
- Part 4 (`part4.html`) — layout page using CSS classes, floating elements, and a footer
- `style.css` — shared stylesheet used to style the pages consistently

## 3. Steps Taken

1. Planned the structure of the website and created the main navigation menu.
2. Built the individual HTML pages for each assignment requirement.
3. Added content such as text, lists, tables, and a profile image.
4. Applied CSS styling to improve the page design and layout.
5. Reviewed each page for consistency, readability, and navigation flow.
